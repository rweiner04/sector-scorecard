About the data

Source

Monthly adjusted closing prices from Yahoo Finance for the eleven Select Sector SPDR exchange-traded funds, one for each S&P 500 sector (XLK, XLF, XLE, XLV, XLY, XLP, XLI, XLB, XLU, XLRE, XLC), and for the SPDR S&P 500 ETF (SPY), which stands in for the S&P 500. Adjusted prices include dividends, so every return here is a total return. The file on this site, sector_returns_2019_2026.csv, holds the monthly returns computed from those prices.

What one row is

One sector in one calendar month: the sector fund's total return that month, the S&P 500's total return the same month, the difference between them, and whether the sector beat the index. Eleven sectors over 93 months make 1,023 rows.

Rows dropped

December 2018 is used only as the starting price for January 2019's return and is not a row. October 2026 is dropped because the month is not complete. No other months or sectors are dropped. Comparisons between years use average monthly figures, so the nine months of 2026 are compared fairly with twelve-month years.

How each summary number is computed

  • Sector-months counted: the number of rows in the current selection.
  • Average monthly return: the average of monthly_return, where monthly return = this month's adjusted close ÷ last month's adjusted close − 1, in percent.
  • Average monthly excess return vs. S&P 500: the average of excess_return = sector monthly return − S&P 500 monthly return, in percentage points (pp).
  • Share of sector-months that beat the S&P 500: the average of beat_sp500, which is 1 when the sector's monthly return is greater than the S&P 500's and 0 otherwise, shown as a percent.

Growth of $100 compounds each month's return in date order. Volatility is the sample standard deviation of monthly returns. A "down month" is a month in which the S&P 500's return was below zero.
